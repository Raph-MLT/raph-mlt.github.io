# Portfolio – Raphaël Maulat

Mon portfolio d'étudiant en Bachelor IA & Data à Ynov Campus Aix-en-Provence.

## Objectif

Projet de fin de module HTML/CSS : présenter qui je suis et mes projets, avec un lien à partager sur mon CV ou LinkedIn.

Le site est fait uniquement en HTML et CSS.

## Pages

- `index.html` : ma présentation et mes projets
- `contact.html` : e-mail, GitHub et CV à télécharger

## Lancer le site

Pas d'installation : ouvrir `index.html` dans un navigateur.
